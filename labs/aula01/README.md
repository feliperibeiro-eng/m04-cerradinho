# Aula 01 – Desafio: padrão de alerta

Projeto no Wokwi: https://wokwi.com/projects/477966012765625345

Pisca-pisca reescrito com `millis()` no lugar de `delay()`. O padrão é dois pulsos curtos (200 ms aceso, 200 ms apagado, 200 ms aceso) seguidos de uma pausa de 1400 ms, num ciclo de 2 s. Como o `loop()` não trava, na Aula 02 o rastreador vai conseguir ler o lacre enquanto o LED pisca.
